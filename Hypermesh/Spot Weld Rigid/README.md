# Spot Weld Rigid Creator

## Purpose

Clusters nearby spot weld elements and creates rigid connections
based on validated node configurations.

## HyperMesh Version

2022.3

## Solver

LS-DYNA

## Inputs

- Spot weld elements
- Distance tolerance
- Destination collector

## Outputs

- Rigid link elements
- Processing report

## Usage

1. Select elements
2. Select destination collector
3. Configure distance tolerance
4. Run tool

## Version

2.0.0
