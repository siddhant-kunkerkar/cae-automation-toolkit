# CAE Automation Toolkit

A collection of engineering automation projects developed to eliminate repetitive and non-value-added tasks from CAE workflows.

The objective is simple:

Automate routine operations.
Reduce manual effort.
Improve consistency.
Allow engineers to focus on analysis, problem solving, and product development.

## Technologies

- HyperMesh Tcl/Tk
- ANSA Python
- Python
- Windows Batch

## Areas

- CAE workflow automation
- Model preparation
- Validation and quality checks
- Reporting and data processing
- Productivity tools
